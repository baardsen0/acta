Guide

This page explains how to log entries, find them quickly, and export them in the format you need.

  1. Go to the Entry tab.
  2. Fill in What, When, Where, and Created by.
  3. Under Who, add each person with + Add person.
  4. Click Save entry.
  • Set your preference in Settings (`24-hour` or `AM/PM`).
  • The Entry form automatically adjusts to match that format.
  • Use current time fills date/time based on your setting.
  • Set User name in Settings.
  • When set, it is used as the default for Created by.
  • Use Search in the Entries tab.
  • Entries are sorted newest first.
  • Use Prev/Next for paging (5 per page).
  • Choose export format in Settings (`MD`, `PDF`, `XLS`, or `JSON`).
  • Click Export in the Entries tab.
  • Export includes all entries, not just current page/search results.
